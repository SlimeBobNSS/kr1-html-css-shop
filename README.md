## Практическая работа №2: Семантическая разметка и структура
* **Выполнено**: Создан каркас страниц с использованием правильных HTML5 тегов.
* **Применение в проекте**:
  - Тег `<header>` используется для единой шапки сайта.
  - Тег `<main>` выделяет основной уникальный контент каждой страницы.
  - Тег `<section>` разбивает главную страницу на логические блоки (`#features`, `#popular`).
  - Тег `<aside>` применен для блока примечания/о проекте и боковой панели фильтров.
  - Тег `<footer>` закрывает страницы и содержит копирайт.

## Практическая работа №3: Формы и интерактивные элементы
* **Выполнено**: Созданы формы для ввода данных с валидацией и модальное окно.
* **Применение в проекте**:
  - Реализовано всплывающее окно `<dialog>` для быстрого бронирования.
  - Использованы разнообразные типы полей: `type="text"`, `type="email"`, `type="tel"`, `type="hidden"`.
  - Для выбора трибун и целей обращения применен тег `<select>`.
  - Поля снабжены обязательными атрибутами `required`, `placeholder` и связкой `label + input` через `id`.

## Практическая работа №4: Введение в CSS и кастомные свойства
* **Выполнено**: Настроен базовый сброс стилей, подключены шрифты и внедрены переменные.
* **Применение в проекте**:
  - В блоке `:root` созданы дизайн-токены гоночной палитры (`--color-bg: #15151E`, `--color-primary: #E10600`).
  - Настроены переменные отступов `--space-md` и скруглений `--radius-md` для быстрой смены стиля сайта.
  - Применен глобальный сброс `box-sizing: border-box`.

## Практическая работа №5: Позиционирование элементов (Position)
* **Выполнено**: Освоена работа с различными типами позиционирования элементов.
* **Применение в проекте**:
  - **`position: sticky`** удерживает шапку `.site-header` вверху экрана при прокрутке.
  - **`position: absolute`** накладывает яркие бейджи статуса гонки `.product-card__badge` в правый верхний угол карточек.
  - **`position: relative`** задан для карточек пилотов, выступая системой координат для бейджей.

## Практическая работа №6: Сетки и макеты (Flexbox и Grid)
* **Выполнено**: Построение сложных сеток страниц без использования устаревших табличных методов.
* **Применение в проекте**:
  - **CSS Grid**: Сетка `.products-grid` автоматически распределяет карточки пилотов в 3 колонки (`repeat(3, 1fr)`). Макет каталога `.catalog-layout` делит страницу на боковой фильтр (300px) и контент (`1fr`).
  - **Flexbox**: Использован в шапке `.site-header__inner` для прижатия логотипа и меню к разным краям через `justify-content: space-between`.

## Практическая работа №7: Методология БЭМ и организация кода
* **Выполнено**: Код полностью переписан по правилам БЭМ (Блок, Элемент, Модификатор).
* **Применение в проекте**:
  - **Блоки**: `.product-card`, `.button`, `.site-nav`.
  - **Элементы**: `.product-card__title`, `.site-nav__link`.
  - **Модификаторы**: `.product-card--featured` (для выделения карточки красной рамкой), `.button--primary` (акцентная кнопка).
  - В коде отсутствуют вложенные цепочки селекторов, что обеспечивает независимость блоков.
